### Ansible docs (ansible-doc)

#### copy

- for copying files from local (master) machine to target machine
    - source can be also remote machine

- OPTIONS
    - content: useful for one-liners instead of giving source file
    - dest: mandatory. 'src' and 'dest' must be same type: file or dir
    - src: local path to source file
        - path can be relative or absolute
    - owner: specify chown like owner of the dest object
    - group: works like owner
    - mode: what is desired permissions of dest file. use 'nnnn' format
        - hox: `stat` file shows symbolic and octal values

#### apt

- manages apt packages

- OPTIONS
    - name: name of package
        - can give multiple
    - state: present for installing, absent for de-install and latest for living in the edge
    - update_cache: updates apt cache before install operation.
        - default is not to update cache

#### file

- for file manipulation in target/slave machine
    - path: mandatory, file or another object under the scope
    - recurse: if true, then set permissions etc. recursive from the path
    - src: when creating (sym)links. what's is source
    - state: absent - deletes the object what is specified in path
    - owner/group/mode: see in copy.

#### user

- for managing user account and attributes

- OPTIONS
    - name: who we are manipulating?
    - create_home: is user deserving home directory
    - comment: Comment section from passwd file, usually the user name.
    - groups: list of groups where user belongs
    - shell: User login shell
    - state: should account exists or not?
    - system: instead of normal user account, create system account
        - not affecting to existing users!

#### authorized_key

- for manipulating SSH keys for user accounts

- OPTIONS
    - user: who is under the scope
    - key: public key
        - string, URL or file
